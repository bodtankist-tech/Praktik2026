ШПАРГАЛКА: ЗАПУСК ДАШБОРДА «ОКО» ЧЕРЕЗ ТЕРМІНАЛИ (VS Code)
================================================================

Дашборд = 2 частини, кожна у своєму терміналі:
  БЕКЕНД   (API + PostgreSQL)  ->  http://localhost:8020/api
                                    документація: http://localhost:8020/docs
  ФРОНТЕНД (сторінка дашборда) ->  http://localhost:8080

Перед запуском: служба PostgreSQL має працювати.
Перше налаштування (пароль БД, .venv, дані) - один раз через ЗАПУСК.bat.


КРОК 1. Відкрити перший термінал
----------------------------------------------------------------
  Меню Terminal -> New Terminal   (або Ctrl + Shift + ~)
  Внизу буде:  PS C:\Users\Bogdan\OneDrive\Документы\Praktik2026>


КРОК 2. Запустити БЕКЕНД (скопіювати рядок повністю, Enter)
----------------------------------------------------------------
  cd "Thema 5\Даш борд аналітика 09.11"; .\.venv\Scripts\python run.py backend

  Готово, коли з'явиться:  Uvicorn running on http://127.0.0.1:8020
  Термінал НЕ закривати - у ньому працює сервер.


КРОК 3. Відкрити другий термінал
----------------------------------------------------------------
  Кнопка "+" праворуч на панелі терміналу
  (або Split - щоб бачити обидва поруч).
  Новий термінал знову відкривається в Praktik2026, тому cd потрібен і тут.


КРОК 4. Запустити ФРОНТЕНД
----------------------------------------------------------------
  cd "Thema 5\Даш борд аналітика 09.11"; .\.venv\Scripts\python run.py frontend

  Браузер сам відкриє http://localhost:8080


КРОК 5. Зупинка
----------------------------------------------------------------
  У кожному терміналі натиснути  Ctrl + C
  (або закрити термінал значком кошика).


КОРИСНІ КОМАНДИ (з папки дашборда)
----------------------------------------------------------------
  Обидва сервери в одному терміналі:
      .\.venv\Scripts\python run.py

  Перевірити API (у третьому терміналі):
      .\.venv\Scripts\python scripts\smoke_test.py

  Перегенерувати дані в БД:
      .\.venv\Scripts\python backend\db\seed.py

  Де я зараз?
      Get-Location

  Повернутися в корінь репозиторію:
      cd "C:\Users\Bogdan\OneDrive\Документы\Praktik2026"

  Повний шлях до папки дашборда (працює з будь-якого місця):
      cd "C:\Users\Bogdan\OneDrive\Документы\Praktik2026\Thema 5\Даш борд аналітика 09.11"


ЗАПУСК СТАНДАРТНИМИ КОМАНДАМИ (без run.py)
----------------------------------------------------------------
  Термінал 1:
      cd "Thema 5\Даш борд аналітика 09.11\backend"; ..\.venv\Scripts\python -m uvicorn api.main:app --port 8020
  Термінал 2:
      cd "Thema 5\Даш борд аналітика 09.11\frontend"; ..\.venv\Scripts\python -m http.server 8080


ТИПОВІ ПОМИЛКИ
----------------------------------------------------------------
  '.\.venv\Scripts\python' is not recognized
      -> Термінал не в папці дашборда. Виконати рядок разом із cd.

  "Бекенд уже працює" / "Фронтенд уже працює"
      -> Сервер уже запущений (в іншому терміналі чи через ЗАПУСК.bat).
         Просто відкрити http://localhost:8080

  "Не вдалося підключитися до PostgreSQL"
      -> Запустити службу postgresql (Win+R -> services.msc)
         або перевірити пароль у backend\.env

  На сторінці "Помилка звернення до API"
      -> Не запущений бекенд: виконати КРОК 2.

  "address already in use" / порт зайнятий
      -> Закрити старий термінал із сервером
         або процес python.exe у Диспетчері завдань.


ЗАПУСК БЕЗ ТЕРМІНАЛІВ
----------------------------------------------------------------
  Подвійний клік по ЗАПУСК.bat у папці дашборда - запускає обидва сервери.
  Зупинка: закрити чорне вікно.
