# Шпаргалка: запуск дашборда «ОКО» через термінали (VS Code)

Дашборд складається з двох частин, і кожна працює у своєму терміналі:
- **бекенд** (API + PostgreSQL) — http://localhost:8020/api, документація http://localhost:8020/docs
- **фронтенд** (сторінка дашборда) — http://localhost:8080

> Перед запуском: служба PostgreSQL має працювати. Перше налаштування (пароль БД, `.venv`, дані) робиться
> один раз через `ЗАПУСК.bat`.

---

## Крок 1. Відкрити перший термінал
- Меню **Terminal → New Terminal** (або `Ctrl + Shift + ~`).
- Внизу з'явиться рядок `PS C:\Users\Bogdan\OneDrive\Документы\Praktik2026>`.

## Крок 2. Запустити бекенд
Скопіювати рядок **повністю** й натиснути Enter:
```powershell
cd "Thema 5\Даш борд аналітика 09.11"; .\.venv\Scripts\python run.py backend
```
Готово, коли з'явиться: `Uvicorn running on http://127.0.0.1:8020`.
Термінал **не закривати**: у ньому працює сервер.

## Крок 3. Відкрити другий термінал
- Кнопка **«+»** праворуч на панелі терміналу (або **Split** ⧉, щоб бачити обидва поруч).
- Новий термінал знову відкривається в `Praktik2026`, тому `cd` потрібен і тут.

## Крок 4. Запустити фронтенд
```powershell
cd "Thema 5\Даш борд аналітика 09.11"; .\.venv\Scripts\python run.py frontend
```
Браузер сам відкриє **http://localhost:8080**.

## Крок 5. Зупинка
У кожному терміналі натиснути **`Ctrl + C`** (або закрити термінал кошиком 🗑).

## Корисне
| Що потрібно | Команда (з папки дашборда) |
|---|---|
| Обидва сервери в одному терміналі | `.\.venv\Scripts\python run.py` |
| Перевірити API (третій термінал) | `.\.venv\Scripts\python scripts\smoke_test.py` |
| Перегенерувати дані в БД | `.\.venv\Scripts\python backend\db\seed.py` |
| Де я зараз? | `Get-Location` |
| Повернутися в корінь репозиторію | `cd "C:\Users\Bogdan\OneDrive\Документы\Praktik2026"` |

Запуск стандартними командами, без `run.py`:
```powershell
# термінал 1
cd "Thema 5\Даш борд аналітика 09.11\backend"; ..\.venv\Scripts\python -m uvicorn api.main:app --port 8020
# термінал 2
cd "Thema 5\Даш борд аналітика 09.11\frontend"; ..\.venv\Scripts\python -m http.server 8080
```

## Типові помилки
| Повідомлення | Причина й рішення |
|---|---|
| `'.\.venv\Scripts\python' is not recognized` | Термінал не в папці дашборда. Виконати рядок разом із `cd` |
| `Бекенд уже працює` / `Фронтенд уже працює` | Сервер уже запущений (в іншому терміналі чи через `ЗАПУСК.bat`). Просто відкрити http://localhost:8080 |
| `Не вдалося підключитися до PostgreSQL` | Запустити службу postgresql (Win+R → `services.msc`) або перевірити пароль у `backend\.env` |
| На сторінці «Помилка звернення до API» | Не запущений бекенд: виконати крок 2 |
| `address already in use` / порт зайнятий | Закрити старий термінал з сервером або процес `python.exe` у Диспетчері завдань |
