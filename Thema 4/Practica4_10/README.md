# Практична робота 4.10. Глибоке навчання в індивідуальному проєкті

**Варіант 1: Image classification.** Простий baseline проти згорткової нейронної мережі (CNN), перевірка аугментації та domain shift.

## Problem contract
- **Input:** зображення рукописної цифри 8×8 пікселів у відтінках сірого.
- **Target:** клас цифри 0–9, мультикласова класифікація.
- **Користувач:** аналітик, якому потрібне автоматичне розпізнавання дрібних рукописних позначок (наприклад, номерів у сканованих формалізованих документах).
- **Критерій успіху:** accuracy на test ≥ 0.97, модель статистично не гірша за лінійний baseline і стійкіша до невеликих спотворень (зсув, шум).
- **Навіщо DL:** CNN використовує просторову структуру зображення (локальні штрихи) та інваріантність до зсуву, яких немає в лінійної моделі на «сплющених» пікселях.

## Дані
Відкритий набір UCI ML «Optical Recognition of Handwritten Digits» з пакета scikit-learn: 1797 зображень, 10 класів. Див. [`data/README.md`](data/README.md). Самі дані в репозиторій не копіюються, вони завантажуються з `sklearn.datasets.load_digits()`. Зберігаються тільки індекси розподілу (`data/split.npz`).

## Як запустити
```bash
pip install -r requirements.txt
cd notebooks
jupyter nbconvert --to notebook --execute --inplace 01_data.ipynb 02_baseline.ipynb 03_dl_experiment.ipynb
```
Ноутбуки запускаються по черзі з каталогу `notebooks/`. Інтернет не потрібен. Відтворюваність забезпечують фіксований seed (`keras.utils.set_random_seed(42)`) та збережений розподіл. Результати отримано з TensorFlow 2.21, scikit-learn 1.8, Python 3.11 на CPU.

## Висновок і обмеження
На чистому test CNN краща за baseline на 1.4 п.п., але bootstrap-інтервал різниці [−0.006; 0.036] включає нуль, тож тут перевага не доведена. Вирішальна перевага CNN D3 — **стійкість до зсуву зображення** (0.98 проти 0.40 у baseline). Обмеження: малий набір, роздільність 8×8, один seed на run. Аугментація зсувами знизила стійкість до шуму. Подробиці в [`results/error_analysis.md`](results/error_analysis.md) та в останньому розділі `03_dl_experiment.ipynb`.

**Наступний крок:** шум в аугментації, оцінка за кількома seed, калібрування впевненості та поріг відмови.
