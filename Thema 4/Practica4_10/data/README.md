# Data card: UCI Optical Recognition of Handwritten Digits (sklearn `load_digits`)

| Поле | Значення |
|---|---|
| Джерело | E. Alpaydin, C. Kaynak (1998). *Optical Recognition of Handwritten Digits*. UCI Machine Learning Repository. Копія входить до scikit-learn (`sklearn.datasets.load_digits`) |
| Ліцензія | CC BY 4.0 (UCI) |
| Чутливість | відкриті дані; персональної, службової чи іншої чутливої інформації немає |
| Обсяг | 1797 зображень |
| Схема | `images`: 8×8, цілі значення яскравості 0–16; `target`: клас 0–9 |
| Баланс класів | 174–183 зображення на клас, збалансовано |
| Пропуски / дублікати | пропусків немає; однакових зображень між train, val і test немає (перевірено в `01_data.ipynb`) |
| Походження | зменшені (32×32 → 8×8, підрахунок пікселів у блоках 4×4) сканування рукописних цифр 43 авторів |
| Обмеження | дуже низька роздільність; обмежене коло авторів; чисті сканування без шуму та спотворень, тож робота на реальних даних може бути гіршою |

## Розподіл
`split.npz` містить масиви індексів `train` (1078), `val` (359), `test` (360). Розподіл стратифікований за класом (60/20/20, `random_state=42`) і створюється в `notebooks/01_data.ipynb`.
