# Картотека — тренажер аналітика

Інтерактивний вебтренажер для особового складу інформаційно-аналітичних підрозділів, побудований за зразком CSS Diner. На «столі аналітика» лежать картки повідомлень. Ті, які треба відібрати, підстрибують. Слухач пише запит до картотеки, а правильно відібрані картки «відлітають».

Застосунок складається з `index.html` і папки `media/` зі знімками. Достатньо відкрити `index.html` у браузері, нічого встановлювати не треба, інтернет потрібен лише для шрифтів. Усі дані навчального сценарію вигадані, а справжні фото й відео техніки лише ілюструють картки.

## Зміст (24 рівні)

| Блок | Рівні | Що вивчається |
|---|---|---|
| Поля та ключові слова | 1–5 | `тип:фото`, `район:Схід`, пошук за основою слова, точна фраза в лапках, неявне «І» |
| Логічні оператори | 6–9 | `АБО`, чергування голосних (`міст АБО мост`), виключення `-` / `НЕ`, дужки й пріоритет операцій |
| Оцінка джерела та інформації | 10–16 | адміралтейська система НАТО (A–F / 1–6), `оцінка:B2`, порівняння `джерело:<=B`, діапазони `інфо:2..3`, F і 6 як «неможливо оцінити» |
| Час, мова, пріоритет | 17–19 | `дата:>=2026-10-25`, періоди `дата:2026-10-10..2026-10-20`, виключення за полем |
| Розпізнавання техніки | 20–23 | поле `техніка:` за знімком (танк, БТР, САУ, РСЗВ, вантажівка, БПЛА), довідник ознак, різниця між згадкою в тексті та знімком |
| Підсумок | 24 | комплексна вибірка для доповіді |

## Синтаксис запитів

| Запис | Значення |
|---|---|
| `слово` | частина слова в заголовку картки |
| `"фраза"` | точний збіг фрази |
| `A B`, `A І B` | обидві умови |
| `A АБО B` | будь-яка з умов |
| `-A`, `НЕ A` | виключити |
| `( … )` | групування |
| `поле:значення` | поля: `тип`, `район`, `джерело`, `інфо`, `оцінка`, `дата`, `мова`, `пріоритет`, `техніка` |
| `<` `<=` `>` `>=` `від..до` | порівняння та діапазон (для `джерело`, `інфо`, `дата`) |

## Команди англійською

Запит приймається обома мовами, їх можна навіть змішувати. Перемикач **УКР / ENG** у редакторі запиту змінює мову, якою показано приклади, шпаргалку, підказки, облікові записи та готову відповідь; уже набраний запит при перемиканні перекладається. Текст для пошуку в заголовку завжди пишеться українською, бо картки українською.

| УКР | ENG |
|---|---|
| `АБО`, `І` / `ТА`, `НЕ` | `OR`, `AND`, `NOT` |
| `тип:` фото, відео, звіт, допис, аудіо, карта | `type:` photo, video, report, post, audio, map |
| `район:` Північ, Південь, Схід, Захід | `region:` North, South, East, West |
| `джерело:`, `інфо:`, `оцінка:`, `дата:` | `source:`, `info:`, `rating:`, `date:` |
| `мова:` укр, англ, інша | `lang:` ua, en, other |
| `пріоритет:` високий, середній, низький | `priority:` high, medium, low |
| `техніка:` танк, бтр, сау, рсзв, вантажівка, бпла | `equip:` tank, apc, spg, mlrs, truck, uav |

Приклад: `(тип:фото АБО тип:відео) район:Схід` = `(type:photo OR type:video) region:East`.

## Можливості

- поки слухач друкує запит, картки, що під нього підходять, підсвічуються;
- після перевірки зайві картки позначаються червоним, пропущені жовтою рамкою;
- помилки в запиті пояснюються українською;
- поступові підказки: на кожному рівні три підказки, від загального натяку до майже готового запиту;
- кнопка «Показати відповідь», рівні, пройдені з готовою відповіддю, позначаються окремо;
- словник команд УКР ↔ ENG у бічній панелі;
- справжні фото військової техніки на картках; відео (РСЗВ «Град», HIMARS, танк Abrams) оживають при наведенні курсора;
- клік по картці відкриває знімок або відео на весь екран; у блоці розпізнавання поле «техніка» приховане, поки рівень не пройдено;
- бали за рівень: 100, мінус 15 за підказку й 10 за хибну спробу (не менше 20), плюс 20 за проходження до 30 с або 10 до 60 с; з готовою відповіддю 10;
- звання за сумою балів: Курсант → Молодший аналітик → Аналітик → Старший аналітик → Провідний аналітик;
- вісім нагород (перший запит, чиста робота, блискавка, серія, bilingual, знавець оцінок, пильне око, доповідь готова);
- таймер рівня, анімація роздачі карток і штамп «ВІДІБРАНО»;
- звуки, синтезовані в браузері (без звукових файлів), з кнопкою вимкнення;
- прогрес, бали, нагороди, мова команд і звук зберігаються в браузері (`localStorage`).
