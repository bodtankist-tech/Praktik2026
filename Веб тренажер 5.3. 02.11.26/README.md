# Картотека — тренажер аналітика

Інтерактивний вебтренажер для особового складу інформаційно-аналітичних підрозділів, побудований за зразком CSS Diner. На «столі аналітика» лежать картки повідомлень зі справжніми знімками техніки. Ті, які треба відібрати, підстрибують. Слухач пише запит до картотеки, а правильно відібрані картки отримують штамп «ВІДІБРАНО» й «відлітають».

Інтерфейс і команди доступні **українською та англійською** (перемикачі УКР / ENG). Усі дані навчального сценарію вигадані, а фото й відео лише ілюструють картки.

## Як запустити

- **Локально:** відкрийте `index.html` у браузері. Інтернет не потрібен: шрифти, фото й відео лежать у папці тренажера.
- **Онлайн:** через GitHub Pages (див. нижче). Слухачі відкривають посилання з телефона чи комп'ютера.

Копіюйте всю папку, а не лише `index.html`.

## Зміст (32 рівні)

| Блок | Рівні | Що вивчається |
|---|---|---|
| Поля та ключові слова | 1–5 | `тип:фото`, `район:Схід`, пошук за основою слова, точна фраза в лапках, неявне «І» |
| Логічні оператори | 6–9 | `АБО`, чергування голосних (`міст АБО мост`), виключення `-` / `НЕ`, дужки й пріоритет операцій |
| Оцінка джерела та інформації | 10–16 | адміралтейська система НАТО (A–F / 1–6), `оцінка:B2`, порівняння `джерело:<=B`, діапазони `інфо:2..3`, F і 6 як «неможливо оцінити» |
| Час, мова, пріоритет | 17–19 | `дата:>=2026-10-25`, періоди, виключення за полем |
| Розпізнавання техніки | 20–25 | `техніка:` за знімком: танк, БТР, САУ, РСЗВ, вантажівка, БПЛА, ППО, гелікоптер; довідник ознак; знімок проти згадки в тексті |
| Перевірка інформації (OSINT) | 26–28 | повторне використання знімка (`знімок:`, відбиток зображення), старий знімок під новим заголовком (`зйомка:`, дата з EXIF), стан метаданих (`метадані:`) |
| Карта | 29–30 | квадрати кілометрової сітки `квадрат:4510`, ділянки `квадрат:4410..4612`, схематична карта з позначками карток |
| Пошук за схожістю | 31 | ранжування TF–IDF `схоже:"рух колони техніки"`, оцінка схожості на кожній картці (зв'язок з практикою 4.15) |
| Підсумок | 32 | комплексна вибірка для доповіді |

## Синтаксис запитів

| Запис | Значення |
|---|---|
| `слово` | частина слова в заголовку картки (українською) |
| `"фраза"` | точний збіг фрази |
| `A B`, `A І B` | обидві умови |
| `A АБО B` | будь-яка з умов |
| `-A`, `НЕ A` | виключити |
| `( … )` | групування |
| `поле:значення` | поля: `тип`, `район`, `джерело`, `інфо`, `оцінка`, `дата`, `мова`, `пріоритет`, `техніка`, `знімок`, `зйомка`, `метадані`, `квадрат`, `схоже` |
| `<` `<=` `>` `>=` `від..до` | порівняння та діапазон (`джерело`, `інфо`, `дата`, `зйомка`; для `квадрат` діапазон задає прямокутник) |
| `схоже:"…"` | схожість за TF–IDF, поріг 0,30 |

## Команди англійською

Запит приймається обома мовами, їх можна змішувати. Перемикач **УКР / ENG** у редакторі змінює мову команд у прикладах, шпаргалці, підказках, облікових записах і готовій відповіді; набраний запит при цьому перекладається. Текст для пошуку в заголовку завжди пишеться українською, бо картки українською (в англійському інтерфейсі під заголовком показано переклад).

| УКР | ENG |
|---|---|
| `АБО`, `І` / `ТА`, `НЕ` | `OR`, `AND`, `NOT` |
| `тип:` фото, відео, звіт, допис, аудіо, карта | `type:` photo, video, report, post, audio, map |
| `район:` Північ, Південь, Схід, Захід | `region:` North, South, East, West |
| `джерело:`, `інфо:`, `оцінка:`, `дата:` | `source:`, `info:`, `rating:`, `date:` |
| `мова:` укр, англ, інша | `lang:` ua, en, other |
| `пріоритет:` високий, середній, низький | `priority:` high, medium, low |
| `техніка:` танк, бтр, сау, рсзв, вантажівка, бпла, ппо, гелікоптер | `equip:` tank, apc, spg, mlrs, truck, uav, sam, heli |
| `знімок:`, `зйомка:`, `квадрат:`, `схоже:` | `image:`, `shot:`, `square:`, `similar:` |
| `метадані:` є, видалено, змінено | `meta:` present, removed, edited |

## Можливості

- **Пояснення помилок по кожній картці:** «№07 зайва: «джерело:<=B» не виконується (джерело: C)», «№12 відкинута вашим запитом: «тип:фото» не виконується (тип: відео)».
- **Поступові підказки:** три на рівень, від натяку до майже готового запиту; кнопка «Показати відповідь».
- **Справжні знімки** військової техніки; відео (РСЗВ «Град», HIMARS, танк Abrams) оживають при наведенні; клік відкриває знімок на весь екран. Поле «техніка» приховане, поки рівень не пройдено.
- **Бали, звання й нагороди:** 100 за рівень, мінус 15 за підказку й 10 за хибну спробу, бонус за швидкість; 5 звань; 10 нагород.
- **Повністю двомовний інтерфейс** (уроки, підказки, помилки, звіти), перемикач УКР / ENG угорі.
- Звуки, синтезовані в браузері, з кнопкою вимкнення; анімація роздачі карток і штамп.
- Прогрес, бали, нагороди, мова й результати заліків зберігаються в браузері (`localStorage`).

### Залік

Кнопка **«Залік»** угорі: 10 випадкових завдань з усіх блоків, 15 хвилин на все, без підказок, готових відповідей і тексту уроку (довідник техніки лишається). Завдання можна пропустити. Наприкінці формується **звіт** з прізвищем, групою, результатом кожного завдання й оцінкою за п'ятибальною шкалою:

| Відсоток | Оцінка |
|---|---|
| 90–100% | 5 (відмінно) |
| 75–89% | 4 (добре) |
| 60–74% | 3 (задовільно) |
| менше 60% | 2 (незадовільно) |

Відсоток рахується зі 100 балів за завдання (мінус 10 за хибну спробу); бонус за швидкість на оцінку не впливає. Звіт можна надрукувати або зберегти як PDF: кнопка «Друк / PDF» друкує лише звіт.

### Таблиця групи

У звіті є **код результату** `KRT-…`. Слухач передає його викладачу, а той вставляє коди в «Таблицю групи» (меню рівнів → «Таблиця групи»): рейтинг за балами й експорт у CSV для Excel. Код містить контрольну суму, тож випадкові зміни відхиляються, але від навмисної підробки він не захищає: для офіційних оцінок звіряйте з надрукованим звітом. Справжня онлайн-таблиця для всієї групи потребувала б сервера; цей варіант працює без нього.

## Публікація через GitHub Pages

1. На GitHub відкрийте репозиторій → **Settings** → **Pages**.
2. У «Build and deployment» оберіть **Source: Deploy from a branch**, гілка `main`, папка `/ (root)`, **Save**.
3. За хвилину-дві тренажер буде доступний за адресою
   `https://bodtankist-tech.github.io/Praktik2026/Веб%20тренажер%205.3.%2002.11.26/`

У корені репозиторію лежить файл `.nojekyll`, щоб GitHub віддавав файли як є, без обробки Jekyll.

## Структура

```
index.html        розмітка
css/style.css     стилі (зокрема для друку звіту)
js/i18n.js        тексти інтерфейсу українською та англійською
js/query.js       мова запитів: розбір, переклад команд, пояснення, TF–IDF
js/data.js        картки, рівні, довідник техніки, карта
js/app.js         логіка: рівні, бали, перегляд знімків, карта, залік, таблиця групи
media/img, video  знімки (640 px) і відео; media/credits.js — автори й ліцензії
fonts/            шрифти woff2 і ліцензії OFL
```
