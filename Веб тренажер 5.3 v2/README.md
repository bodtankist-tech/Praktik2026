# Тренажер аналітика: відбір повідомлень за вимогою керівника (версія 2)

Друга версія вебтренажера, перероблена з урахуванням рецензії викладача на першу версію ([`Веб тренажер 5.3. 02.11.26`](../Веб%20тренажер%205.3.%2002.11.26/README.md)).

## Навчальна мета

**Навчитися швидко перетворювати усну вимогу керівника на точний запит до бази повідомлень і враховувати при цьому оцінку джерел за адміралтейською системою.**

Тренажер відпрацьовує одну практичну навичку. Розпізнавання техніки, OSINT, карти та інші теми з першої версії сюди свідомо не ввійшли.

## Що змінено за рецензією

| Зауваження | Як враховано |
|---|---|
| Забагато візуальних ефектів, незрозуміло, що робити | Прибрано анімації, картки й декор. Повідомлення подано звичайною таблицею. Стартовий екран у трьох кроках пояснює, що робити, і окремо попереджає, що клікати по таблиці не треба |
| Бракує чіткої навчальної мети | Мету сформульовано одним реченням на стартовому екрані. Кожен рівень має завдання у формі **вимоги керівника** |
| 32 рівні забагато | 8 рівнів, кожен відпрацьовує одну навичку. Проходження займає 20–30 хвилин |
| Навичка має бути практичною | Слухач не відгадує, які картки «підстрибують», а сам перекладає вимогу на запит. Після перевірки він бачить, які повідомлення зайві, а які пропущені |

## Рівні

| № | Навичка | Вимога керівника (скорочено) |
|---|---|---|
| 1 | Відбір за кількома полями | усі фото з району «Схід» |
| 2 | Пошук за основою слова | усе про колони техніки |
| 3 | Оператор АБО, чергування голосних | усе про мости (міст / мост) |
| 4 | Виключення | лише готові звіти, без чернеток |
| 5 | Дужки | фото й відео, але лише зі Сходу |
| 6 | Адміралтейська оцінка | джерело A–B, інформація 1–2 |
| 7 | «Неможливо оцінити» (F, 6) | перелік на додаткову перевірку |
| 8 | Підсумок | вибірка для доповіді за п'ятьма умовами |

## Як запустити

Відкрийте `index.html` у браузері. Інтернет не потрібен. Копіюйте всю теку, а не лише `index.html`.

## Структура

```
Веб тренажер 5.3 v2/
├── index.html            три екрани: мета → рівень → підсумок
├── css/style.css         оформлення
├── js/levels.js          база повідомлень і рівні (редагує викладач)
├── js/query.js           мова запитів
├── js/app.js             логіка інтерфейсу та прогрес
├── docs/metodychka.md    методичні рекомендації для викладача
└── tests/check_levels.js автоматична перевірка рівнів
```

## Перевірка рівнів

```
node tests/check_levels.js
```

Скрипт перевіряє кожен рівень: еталонний запит має відбирати частину записів (не нуль і не всі), а типові хибні запити з поля `traps` мусять давати інший результат. Запускайте його після кожної зміни `js/levels.js`.

Усі дані навчального сценарію вигадані.
